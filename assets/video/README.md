# Video folder (optional)

The demo video currently shown on the page is `asset vid/ModCut_EN_with_captions_v2.mp4`
in the repository root, not this folder.

You can use this folder for a replacement video or a poster image instead.
Then update `data-video-file` / `data-video-poster` on `#app-video` in `index.html`.

See the main `README.md` → "The demo video" for full instructions.
